# DeadlineDock 0.2.1 — 3 November 2026

Comfortable appearance: Midnight by default, Forest and warm Sand alternatives;
saved per-browser choice, softer surfaces, clearer supporting text, explicit
status colours, visible keyboard focus and reduced-motion support. Theme changes
preserve forms. The Windows host window is dark and includes the application icon.
Theme controls are translated in all eleven interface languages.

Department hierarchy, role/unit access, leadership dashboard, escalation rules,
attachments, backup/restore and organisation licensing remain as in 0.2.0.
No schema change or new licence is required. Maximum EUR 10 per organisation,
one payment, unlimited internal workstations; manual licence requests by email.

Self-contained Windows 10/11 x64 preview, unsigned. Alerts remain in-app and need
a running host; no email/SMS, automated payment checkout or accreditation is added.
Original source remains private. Public downloads include customer documentation
and required third-party notices, with no private issuer/key or workspace data.
