What do I need to install it?

Windows 10 or 11, x64. The package includes its runtime, so there is no separate .NET installation. Start the Windows host and use its browser interface.

Can several workstations use the same register?

Yes, through one central Windows host and configured HTTPS. Clients use a browser. Separate default installations do not synchronise automatically; the host must remain running for reminders.

Are reminders sent by email or SMS?

This preview provides in-app notices and Windows host notifications. It does not send email or SMS. The host checks reminders every minute while it is running.

What happens after the 30-day evaluation?

Reading existing information, CSV export and backup remain available. A signed organization licence enables continued changes. Request the licence by email; the price is at most €10 for the organization.

Can we use it for a large or regulated organization?

Start with a controlled pilot. This unsigned preview has role/organization access controls, but no SSO, two-factor authentication, document-classification controls or regulatory accreditation. Validate security, capacity and your own procedures before a larger deployment.

What exactly does one organization mean?

One named legal entity, including its departments and branches. Separate incorporated companies, subsidiaries or agencies require their own licence. See the full terms for the purchased major version.
